Project overview

The Student Management System is a web-based application for managing student information and supporting administrative, teacher and student workflows. It brings records, attendance, results, fees and reports together in one place, with separate dashboards for each role.

It is built with Django and PostgreSQL, includes REST API integration, and is deployed online so it can be used from any browser.
